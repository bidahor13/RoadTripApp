# RoadTripApp

RoadTrip Match is a React single-page app built with Vite.

## Run locally

Requires Node.js 14.18 or newer.

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Vite writes the static production site to `dist/`. Deploy the contents of that folder to a static host, or configure the host to run `npm run build` and serve `dist/`.

The trip form currently collects the start and destination and confirms them in the page. Live directions and route search are not connected yet.
